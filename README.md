# 📱 Portafolio Interactivo tipo iPhone

Simulación funcional de un iPhone construida desde cero con **HTML, CSS y JavaScript** — sin frameworks. Cada app dentro del teléfono es un proyecto independiente, integrado dentro del dispositivo mediante `iframe`.

🔗 **Demo en vivo:** (https://yasircordu10-sys.github.io/iPhone-Portafolio/)

## Apps incluidas

- **🧮 Calculadora** — operaciones básicas, interfaz tipo iOS.
- **🃏 Blackjack** — lógica completa de mazo, cálculo de puntaje (As como 1 u 11), turno automático del dealer, reinicio de partida.
- **🛒 AmazonasPrimo** — tienda con catálogo de productos, carrito, checkout con opciones de envío, y guardado de datos con `localStorage`.
- **📄 CV** — currículum interactivo con zoom.

## Tecnologías

- HTML5 / CSS3 (Grid, Flexbox, `backdrop-filter`, variables CSS)
- JavaScript (ES Modules, manipulación del DOM, eventos)
- `localStorage` para persistencia de datos

## Cómo correrlo localmente

Este proyecto usa módulos de JavaScript, así que necesita un servidor local (no funciona abriendo el HTML directo por `file://`):

1. Clona el repositorio
2. Abre la carpeta con la extensión **Live Server** de VS Code (clic derecho en `index.html` → "Open with Live Server"), o corre `python -m http.server` desde la terminal
3. Entra a `index.html` en el navegador
